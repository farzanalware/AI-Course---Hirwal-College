# AI-Course---Hirwal-College
Python project that generates a histogram to visualize the distribution of exam scores 
## Project Overview

This project demonstrates how to visualize exam score distribution using Python.

## Tools and Libraries

- Python
- Anaconda Spyder
- NumPy
- Matplotlib

## How It Works

The program uses NumPy to generate 1,000 random exam scores with a mean of 70 and a standard deviation of 10.

A histogram is created using Matplotlib to show how the scores are distributed across different score ranges.

- X-axis represents the exam scores.
- Y-axis represents the frequency of scores.
- The red dashed line represents the mean score.
- The histogram uses 30 bins to group the scores.

## Output

The resulting graph shows that most exam scores are concentrated around 70, while fewer scores appear at the lower and higher ends of the distribution.
